# CyberSafe SW maintenance

Preserve the approved visual design unless Josh requests a design change.

The production source is `CustardCode/CyberSafeWebsite`, branch `main`. Render builds `dist/` with Node24 and deploys the static site using render.yaml. The old Netlify deployment is a fallback; its function is dormant. The legacy root `index.html`, `style.css`, `script.js` and `images/` are retained for history; edit `src/` and `public/assets/` for the current website.

Before publishing a change, run:

```
node scripts/build.ts
node scripts/check.mjs
node --test tests/contact.test.mjs
```

For a visible change, inspect the affected pages at desktop and mobile widths. Preserve accessibility, readable contrast, phone links, metadata and the real sample PDF.

Never commit passwords, API keys or private environment files. If server-side delivery is requested later, store credentials only in the configured backend's private environment; never include secrets in the Render static site. Keep `emailReady` false until mailbox delivery is verified and `contactEnabled` false until real form arrival and reply-to have been tested. A provider acceptance response alone does not prove inbox arrival. Keep analytics disabled unless Josh requests it.

Use a branch and pull request for reviewable changes. Production deploys follow `main`; a merged change can publish automatically. Use Render deployment history or a reviewed GitHub revert to restore a prior build; check DNS and environment settings separately. Preserve `archive/pre-launch-2026-10-15` and the old site's history.

Do not change domain nameservers, transfer the domain, purchase products or alter subscriptions without Josh's approval. Preserve email DNS when changing website DNS. Consult `DEPLOYMENT.md` and the current launch record before changing integrations.

Render launch configuration is tracked in render.yaml and generated by scripts/build.ts. For Render changes, rebuild and include the updated render.yaml so CSP hashes stay aligned with the page metadata. SITE_HOST=Render selects correct privacy wording. Keep DNS at GoDaddy and preserve mail records. The custom domain is verified on Render; Netlify is retained as a fallback only.
